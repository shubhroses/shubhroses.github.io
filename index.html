DevSecOps engineer in Palo Alto, California

I build and run the infrastructure that gets software and machine learning models into production: Kubernetes platforms, CI/CD pipelines and GPU inference, in the cloud and on premises.

What I work on

  • Kubernetes platform. Helm overlays for applications deployed with Argo CD on RKE2 and GKE, and the autoscaling, ingress and Terraform-managed cloud resources around them.
  • CI/CD. GitLab CI pipelines that build and scan container images and produce an SBOM for each one, and a self-service pipeline for database schema changes.
  • ML infrastructure. A FastAPI service that runs multi-stage ML pipelines in containers, and automation for serving large language models with vLLM on GPU nodes.

Projects

My day-to-day work is in private repositories. These are personal projects.

  • inference-on-kubernetes. An inference-style API with a Helm chart, Prometheus error-budget alerts, a Grafana dashboard and KEDA autoscaling. GitHub Actions creates a kind cluster on two Kubernetes versions and tests rollouts, node drains, scaling and alerting under load. The model is a stand-in.
  • signed-image-pipeline. A GitHub Actions pipeline that scans a container image, writes an SBOM, then signs and attests it with keyless cosign, and a Kyverno policy that admits nothing else. Every release tests nine accept and reject cases on a kind cluster.
  • rocket-telemetry-pipeline. A data pipeline over synthetic rocket engine telemetry: a Python generator that injects data-quality faults, a cleaner that validates and de-duplicates, dbt models for Redshift and a Streamlit dashboard.
  • nba-game-prediction. A Prefect flow lands the live NBA scoreboard in S3 and a loader copies it into Snowflake; dbt models flatten the raw JSON; scikit-learn notebooks backtest win prediction; a React app shows bookmaker favourites.
  • finance-tracker. A Streamlit dashboard for analysing a stock, comparing tickers and reviewing a portfolio, with Yahoo Finance data and Plotly charts.
  • algoVisualizer. A Flask and p5.js app that animates five sorting algorithms.
